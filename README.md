## 🚀 Sobre mis proyectos web
Los proyectos que verás en este portafolio son **Sistemas de Reservas y Catálogos Digitales** construidos con tecnologías web estándar (HTML, CSS y JavaScript puro). 

¿Por qué uso estas tecnologías y no frameworks complejos?
*   **Velocidad:** Cargan en menos de 2 segundos.
*   **Cero costos de servidor:** No requieren bases de datos costosas; se alojan gratis en GitHub Pages.
*   **Integración directa:** Conectan los pedidos o citas directamente al WhatsApp del negocio.
