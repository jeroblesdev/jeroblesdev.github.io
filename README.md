# Portafolio Web - Jeremias Robles

¡Bienvenido a mi portafolio de desarrollo web! 

Aquí encontrarás demos interactivas de los sistemas que creo para negocios locales. Mi especialidad es el desarrollo frontend utilizando HTML, CSS y JavaScript puro (Vanilla JS).

## 🚀 Proyectos Incluidos
*   **Barbería El Clásico:** Sistema de reservas con integración a WhatsApp.
*   **Salón Lumière:** Agenda automatizada para salón de belleza.
*   **Papas Locas:** Catálogo con carrito de compras y envío de pedidos.
*   **Farmacia Demo:** Diseño web para el sector salud.
